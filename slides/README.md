# Slides source of truth

The Google Slides deck is the published copy; these markdown files are the source.
Edit the `.md`, then apply it to the deck. Log each change in `CHANGELOG.md`.

- Deck: https://docs.google.com/presentation/d/1m5_Hdi2S49LgfyBO1Pv7bPTnpW-e7zE9Nx3kfZUpGAY/edit
- One file per new or changed slide. Frontmatter says where it goes and whether it is applied.
- `status: draft` = only in the repo. `status: applied` = copied into the deck.
- Rules: no days on the flow slide, no Adhian Gurus there, no token-saving or cost figures without a measurement or a cited source.

Applying (until the Slides connector is installed): paste the text into the deck by hand, or
File > Import slides on a .pptx built from these files.
